### Perfil

Desarrollador de software autodidacta. Construyo sistemas de punta a punta que conectan aplicaciones web, automatizaciones, APIs, servidores e infraestructura en entornos reales de producción, incluyendo integración con dispositivos IoT.

En **[Encaxa](https://encaxa.com.ar)** lidero proyectos de automatización, integración de sistemas, desarrollo web y consultoría IT para empresas en Argentina, Latinoamérica y España.

<sub>Self-taught Software Developer focused on full-stack systems, automation, API integrations, Linux/cloud infrastructure, and production IoT.</sub>

### Qué construyo

| Área | Enfoque |
|---|---|
| **Full-Stack & Web** | Aplicaciones web reactivas, paneles operativos e interfaces interactivas (`TypeScript`, `React`, `Vite`, `Three.js`). |
| **Automatizaciones & APIs** | Backends, servicios de integración, sincronización entre plataformas y comunicación en tiempo real (`Python`, `Flask`, `REST`, `WebSockets`). |
| **Infraestructura & Datos** | Servidores Linux, despliegues reproducibles, proxies reversos y persistencia (`Docker`, `Nginx`, `PostgreSQL`, `Supabase`, `Vercel`). |
| **Desktop & Hardware** | Herramientas de escritorio local-first (`Tauri`, `Rust`, `Electron`) e integración software–hardware (`ESP32`, `MQTT`). |
